# Anugu Vaishnavi - Personal Portfolio

Welcome to my personal portfolio! This is a modern, responsive, and dynamic web application built with **Next.js**, **React**, and **Tailwind CSS**. It showcases my projects, technical skills, certifications, and experience in Artificial Intelligence, Machine Learning, and Full-Stack Development.

## Features
- **Dynamic Slide Layout:** Smooth transitions between sections (About, Skills, Projects, Certifications, Contact).
- **Interactive UI:** Features micro-animations using Framer Motion and an interactive AI Chat widget.
- **Dark/Light Mode:** Seamlessly switch between themes.
- **Downloadable Assets:** Easy access to download my latest Resume and CV.

## Tech Stack
- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React

## Getting Started

First, install the dependencies:
```bash
npm install
```

Then, run the development server:
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
